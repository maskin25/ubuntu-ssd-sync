Ubuntu SSD Sync

Privacy policy

This policy describes Ubuntu SSD Sync, a personal synchronization setup operated by the owner of the GitHub account maskin25. It is intended for that owner's own Google account, not public enrollment.

Google data accessed and purpose

The setup uses rclone and the Google Drive API. With authorization, it accesses file contents and metadata, including names, identifiers, folder relationships, sizes, modification times and available checksums. It can upload, download, update, rename and delete files and folders to maintain bidirectional synchronization between My Drive and the owner's Ubuntu SSD. Native Google documents and paths matching the configured exclusions are not synchronized. A change or deletion on one side may propagate to the other; this is not an independent backup.

Storage and access

Synchronized file contents are stored on Google Drive and the owner's local disk. OAuth credentials and refresh tokens are stored locally in a restricted configuration file, separate from the mirrored disk. Local synchronization state and logs can contain file paths, metadata and error messages. People and software granted access to the owner's computer or Google account may be able to access these data.

Sharing and use

The synchronization setup transfers data between Google Drive and the owner's computer. It does not sell Google user data, use it for advertising, or use it to train generalized AI models. OAuth credentials and Drive contents are not uploaded to this public website or its source repository. This policy concerns the synchronization setup, not separate applications the owner may subsequently use to process their files.

Retention and deletion

Files are retained until the owner deletes them or synchronization propagates a deletion. Google Drive trash and retention behavior depend on Google and the configured client. Local logs and synchronization state remain until the owner removes them. Revoking OAuth access stops future authorized access but does not automatically erase previously downloaded files, logs or cloud files.

Control and revocation

The owner can stop synchronization, change exclusions, remove local credentials, delete local data and revoke the application's access in the Google Account third-party connections settings. No password is required by this website.

Website hosting

This informational website is hosted by GitHub Pages. It has no application login, upload form or embedded analytics added by the operator. GitHub may process technical request information under its own privacy policies.

Contact and changes

For questions or deletion assistance, contact the operator via GitHub Issues. Never include credentials or private file contents in a public issue. Policy changes will be published on this page and recorded in the repository history.
