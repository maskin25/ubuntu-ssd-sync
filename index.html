Ubuntu SSD Sync

A personal, single-user file synchronization setup operated by the owner of the GitHub account maskin25, using rclone to synchronize Google Drive My Drive with the owner's Ubuntu SSD.

What it does

With the owner's permission, the setup lists, downloads, uploads, updates, renames and deletes ordinary files and folders to keep both sides synchronized. Configurable exclusions keep selected local dependencies, caches and other files out of synchronization. Native Google documents are excluded.

This is not a public file-storage service. This website does not sign visitors in to Google or receive Google Drive files or OAuth tokens.
